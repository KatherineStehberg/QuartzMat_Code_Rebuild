# Estudio UX/UI recuperado — síntesis de implementación

## Propósito
Definir una experiencia digital coherente, segura y centrada en el usuario, facilitando
la navegación, la comprensión de los productos y el proceso de compra.

## Objetivos de diseño
- Consistencia visual.
- Identidad de bienestar y relajación.
- Confianza y seguridad.
- Optimización responsive.
- Guía mantenible para futuras iteraciones.

## Benchmarking recuperado
Referencias:
- Amethyst BioMat
- HigherDOSE
- tiendas holísticas online

Aprendizajes:
- lenguaje simple;
- estética profesional;
- imágenes y storytelling con propósito;
- navegación clara;
- equilibrio entre estética e información.

## Usuario / mapa de empatía
El estudio identifica un usuario que:
- investiga antes de comprar;
- compara precios y materiales;
- busca información confiable;
- necesita claridad;
- quiere una compra tranquila y segura.

## Paleta UX recuperada

## Gaps detectados en evaluación original
El estudio fue evaluado 3/5 (60%) porque faltaban:
- flujo real de navegación;
- componentes UI completos;
- tipografías;
- wireframes/mockups;
- sitemap operativo;
- criterios responsive/accesibilidad.

## Cómo se corrigen en este rebuild
- navegación definida;
- sistema de componentes;
- jerarquía tipográfica;
- estados de botones y carrito;
- responsive;
- estructura de producto -> selección -> carrito;
- documentación para backend/checkout.
