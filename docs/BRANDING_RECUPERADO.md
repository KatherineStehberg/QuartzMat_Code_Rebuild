# Branding recuperado — QuartzMat

## Conceptos de marca
- vitalidad;
- energía;
- plenitud;
- relajo;
- comodidad;
- naturaleza;
- meditación;
- bienestar.

## Paleta histórica del branding
- Negro `#000000`
- Blanco `#FFFFFF`
- Púrpura `#800080`
- Verde azulado `#008282`
- Gris azulado `#555363`

El estudio UX posterior agrega una paleta más suave:
- `#F5F1EC`
- `#9FB2A1`
- `#D8CFC4`
- `#E6E4E1`

## Dirección fotográfica
Fotografía orientada a:
- relajación;
- meditación;
- ambientes naturales;
- producto como protagonista;
- personas en situaciones de bienestar y plenitud.

## Decisión para el rebuild
La UI usa la paleta suave UX como base y conserva teal/púrpura/gris azulado como
acentos de identidad, con un lenguaje visual moderno y comercial.

## Logo
No se recreó el logotipo exacto desde una imagen de baja fidelidad. El prototipo usa
un wordmark temporal `QuartzMat` + monograma `Q`. Antes de producción debe sustituirse
por el archivo vectorial oficial si está disponible.
