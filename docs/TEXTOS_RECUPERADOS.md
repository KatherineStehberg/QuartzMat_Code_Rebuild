# Textos recuperados — QuartzMat

## Objetivo principal del sitio
Vender QuartzMat, la cama de cuarzo portátil y plegable, junto con:
- fundas de colores;
- versiones para niños;
- mantas de peso rellenas de cuarzo para adultos y niños.

La experiencia debe permitir que la persona:
1. entre;
2. entienda en menos de 10 segundos qué es el producto;
3. vea claramente qué puede comprar;
4. pueda comprar fácilmente.

- bienestar moderno, no esotérico.
